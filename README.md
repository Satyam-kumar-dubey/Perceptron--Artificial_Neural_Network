
# 🌸 Perceptron and Artificial Neural Network (ANN) — Deep Learning from Scratch

## 📘 Overview
This project is part of my **Deep Learning learning journey**, where I implemented a **Perceptron** and a **multi-layer Artificial Neural Network (ANN)** from scratch using **Python** in **Google Colab**.  
The models are trained and evaluated on the **Iris dataset** from [Kaggle](https://www.kaggle.com/datasets/uciml/iris) to classify flower species based on petal and sepal measurements.

The goal of this project is to understand the **core mathematical and computational principles** behind neural networks — including forward propagation, activation functions, and gradient descent optimization.

## 🌼 Dataset Description — *Iris Dataset*
The **Iris dataset** is a classic dataset used in pattern recognition and machine learning.  
It contains **150 samples** from **3 flower species** — *Setosa*, *Versicolor*, and *Virginica* — with 4 features each:

| Feature | Description |
|----------|--------------|
| Sepal Length | Length of the sepal in cm |
| Sepal Width  | Width of the sepal in cm  |
| Petal Length | Length of the petal in cm |
| Petal Width  | Width of the petal in cm  |

The task is to classify each sample into one of the three Iris species.

---

## ⚙️ Implementation Details

### 🟢 Perceptron Model
- Implemented a **single-layer perceptron** from scratch using only NumPy.  
- Used a **step activation function** for binary classification.  
- Trained using **gradient descent** to minimize classification error.  
- Key steps:
  - Initialize weights and bias  
  - Compute activation  
  - Update weights based on prediction error  

### 🔵 Artificial Neural Network (ANN)
- Implemented a **multi-layer feedforward neural network** manually.  
- Used **ReLU** and **Softmax** activations for non-linear mapping.  
- Implemented **forward propagation**, **backpropagation**, and **adam**.  
- Trained on all three classes for multi-class classification.
